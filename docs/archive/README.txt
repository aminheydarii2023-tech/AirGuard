AirGuard - City Search Update

How to apply:
1. Close the browser tab running the app (optional; Vite can also hot-reload).
2. Extract this ZIP into the root folder: airguard-ai-dashboard
3. Allow Windows to replace the existing files.
4. In the project terminal, run: npm run build
5. If build succeeds, run: npm run dev
6. Test city search with: تهران, London, Istanbul
7. Select a result and wait for the AQI and pollutant cards to update.

This update replaces only files under src. It does not include node_modules or dist.
